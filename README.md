# Yield Curve-Based Recession Prediction

## 1. Project Overview
This project examines the relationship between the U.S. Treasury yield curve and economic recessions. The objective is to estimate recession probabilities using the yield spread as a predictive indicator.

## 2. Data Sources
- **FRED (Federal Reserve Economic Data):** Historical U.S. Treasury yield data.
- **NBER (National Bureau of Economic Research):** Historical U.S. recession dates.

## 3. Research Reference
https://www.newyorkfed.org/medialibrary/media/research/current_issues/ci2-7.pdf
